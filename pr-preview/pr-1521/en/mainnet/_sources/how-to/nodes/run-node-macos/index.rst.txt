Run a node on macOS (deprecated)
================================

.. admonition:: At a glance

   This section covers installing and configuring a Concordium node on macOS. Choose a guide below based on what you need to do.

.. warning::

   The macOS package distribution is deprecated. For existing installations,
   follow :ref:`migrate-macos-to-docker` to move to Docker Desktop.
   Keep existing node data and validator keys during migration.
   The guides below remain available for existing package installations.
   For new installations, use the macOS tabs in
   :ref:`install-node-docker-image`.
